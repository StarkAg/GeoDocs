### Common Issues


**Issue: HTTPS not working**
1. Check Cloudflare SSL mode is "Full"
2. Verify Nginx is running: `systemctl status nginx`
3. Check SSL cert: `ls -la /etc/ssl/certs/ribil.crt`
